# QR Attendance System

## Install

```bash
npm install
```

## Run

```bash
node bot.js
```

Open:

```text
http://localhost:3000
```

## Usage

1. Upload IITK ID QR image
2. QR decoded
3. Roll number extracted
4. Attendance marked

## Report

Visit:

```text
http://localhost:3000/report
```

- qr.js
- parser.js
